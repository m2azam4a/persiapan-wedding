# Persiapan Nikah (Wedding Planner)

Aplikasi jadwal pernikahan berbasis web (HTML).  
Bisa dibuka gratis lewat **GitHub Pages**.

## Deploy ke GitHub Pages (sekali saja)

1. Login [github.com](https://github.com) → **New repository**.
2. Nama contoh: `persiapan-nikah` → buat **Public** → Create (tanpa centang README).
3. Di repo kosong: **uploading an existing file**.
4. Drag **isi** folder `wedding-planner-html` (bukan foldernya):
   - `index.html`, `gantt.html`, `daily.html`, `vendors.html`, `settings.html`
   - folder `css/`, folder `js/`
   - `README.md` (opsional)
5. Commit changes.
6. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch **main** → folder **/ (root)** → Save.
7. Tunggu 1–2 menit. Link biasanya:  
   `https://USERNAME.github.io/persiapan-nikah/`

## Cara pakai setelah online

1. Buka link Pages di atas.
2. Kerjakan progres di halaman **Jadwal**.
3. Progress **otomatis tersimpan di browser** (perangkat yang sama).
4. Cadangan manual: **Simpan cadangan** → file `cadangan-persiapan-nikah.json` (simpan di Drive/WA).
5. Pindah HP/laptop: **Impor cadangan** → pilih file JSON itu.

## Deploy ulang (kalau ada update kode)

Ganti file di repo (upload lagi / edit), tunggu 1–2 menit.  
**Progres Anda tidak hilang** — ada di browser atau file cadangan JSON, bukan di GitHub.
